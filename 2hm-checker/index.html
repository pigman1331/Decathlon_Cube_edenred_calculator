二手寄賣收件查詢

輸入商品名稱或關鍵字，立即判斷能不能收

收件大原則（2026 OCT）
  • EC／運動商城有賣的運動用品，不限品牌，經夥伴判斷安全、衛生無虞即可免費寄賣。
  • 一律不收：缺件、有安全／衛生疑慮、違法或侵權、非運動用途、氧化生鏽水解、標有「贈品不得轉售」。
  • 「有條件」請看卡片說明：限九成新＝僅有輕微使用痕跡；限完美如新＝無使用痕跡。
  • 查不到或有爭議的物品，由城市與 Ted 共同決定。
回覆話術（賣家／買家／夥伴）

先確認溝通對象是誰：賣家、買家、還是夥伴。查詢到「不可收」的商品時，卡片下方會直接顯示對賣家的建議回覆。

🙋 賣家｜不可寄賣的商品

為什麼 A 店有收、B 店沒收？
回歸活動辦法確實執行，並通知 Ted 協調他店下架。若活動辦法沒有特別規範，以城市為單位討論後，和 Ted 確認是否開放收件。

🛒 買家

之前有看過這個，為什麼這次活動都找不到？
建議回覆
賣家寄賣的商品每次活動都不一樣，你可以參考門市賣場看看有沒有類似的商品哦～有需要幫你介紹嗎？

👥 夥伴

這次放寬許多寄賣類別，為什麼？
之前活動目標是提高媒合率，所以才忍痛捨棄部分媒合率較低的類別。這次為了和收購服務做出區隔，希望放寬運動類別、降低寄賣門檻，讓更多顧客藉由活動認識迪卡儂的各種循環服務，達到「收購服務＋寄賣服務」1+1 大於 2 的效果。
資料管理（匯入收件標準）

可直接選擇收件標準的 Excel（.xlsx）或 CSV 檔，系統會自動對應欄位：類別、品項、關鍵字、判定、條件說明、備註、原因類型（原因類型：安全性／衛生／非運動用途／狀況不佳／法規爭議／其他限制，決定不可收時顯示的回覆話術）。沒有「判定」欄時，會依內容中的「不收／不可」「可收」字樣自動判斷。

匯入後只存在這台裝置的瀏覽器。要讓所有人都看到，請按「下載 CSV」，再把檔案覆蓋到 GitHub 專案的 data/standards.csv。
